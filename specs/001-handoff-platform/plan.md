# Implementation Plan: Handoff — Interactive Developer Handover Tool

## Summary

Handoff is a two-product system that transforms AI-assisted codebase walkthroughs into committed, structured documentation. Phase 1 builds the AI Toolkit — a drop-in `.handoff/toolkit/` folder of skills and rules that instructs Claude Code to autonomously scan a project, infer all documentation fields (business context, depth, decisions, warnings) from code signals, and produce schema-valid Markdown nodes without requiring any giver interaction. An optional `/handoff-review` skill provides a post-generation interactive refinement pass, walking through AI-inferred fields and allowing corrections. Phase 2 builds the VS Code Extension — a TypeScript panel that reads the committed output and renders it as a navigable, code-linked sidebar. The two phases are separated by a quality gate: Phase 2 begins only after Phase 1 output can be dogfooded on the Handoff project itself.

## Technical Context

**Language/Version**:
- Toolkit: Markdown + YAML (no compilation — AI-readable instruction files)
- Extension: TypeScript 5.x

**Primary Dependencies**:
- Extension: `vscode` API, `gray-matter` (frontmatter parsing), `marked` (markdown → HTML)
- Toolkit: None (plain text files read by the AI agent)

**Storage**:
- Toolkit output: `.handoff/output/` (committed Markdown + JSON files)
- Session cache: `.handoff/session.json` (gitignored JSON, read/written by AI)
- Extension progress: VS Code `workspaceState` (key: `handoff.readProgress`)

**Testing**:
- Extension: VS Code Extension Test Runner (`@vscode/test-electron`), fixture-based tests
- Toolkit: Manual dogfood test (run `/handoff-start` on this repo, validate output)

**Target Platform**:
- Toolkit: Any project where Claude Code (or compatible agent) is active
- Extension: VS Code 1.85+ (desktop, not web)

**Project Type**: Drop-in toolkit (Phase 1) + VS Code extension (Phase 2)

**Performance Goals**:
- `/handoff-start` autonomous run completes on a 10–20 section project without waiting for giver input
- Extension sidebar renders within 500ms of workspace open

**Constraints**:
- Toolkit must be fully offline (no network calls)
- Extension must be fully offline (git operations are local)
- Toolkit must work without npm install (drop-in only for MVP)
- `inferred_fields` field is optional in node frontmatter — extension must handle its absence gracefully

## Phase 1: Toolkit

### Deliverables

1. **Updated `handoff-start` SKILL.md** — rewrite for autonomous mode:
   - Remove all WHY-question prompts
   - Add inference logic: sources per field (README, docstrings, commit msgs, `git diff`, complexity signals)
   - Write `inferred_fields` list to each node's frontmatter
   - Add delta re-run logic: read `generated_at_sha` → `git diff --name-only <sha> HEAD` → update only changed nodes
   - Record new `generated_at_sha` at completion

2. **New `handoff-review` SKILL.md** — post-generation interactive refinement:
   - Walk nodes in index order (core → supporting → peripheral)
   - Show each `[AI-guessed]` field (from `inferred_fields`) with label
   - Accept confirm / skip / rewrite per field
   - Remove confirmed fields from `inferred_fields`; re-validate after each correction
   - Skip nodes with empty `inferred_fields` (already confirmed)
   - End with summary: N nodes changed, M accepted as-is
   - Support `--help` flag: display interaction guide before starting

3. **Updated `session-protocol.md`** — remove interactive Q&A references; add `reviewing` and `paused_review` state handling

4. **Unchanged**: `handoff-validate/SKILL.md`, `output-schema.md`, `.gitignore`, `SKILL.md` (master), `CLAUDE-snippet.md`

### Phase 1 Gate

Run `/handoff-start` on this repository (the Handoff project itself). All produced nodes must pass `/handoff-validate`. At least one node covering the toolkit architecture must have a non-empty `business_context` and at least one `code_ref`. This validates that the autonomous inference produces genuinely useful output before Phase 2 begins.

## Phase 2: VS Code Extension

### Deliverables

1. **`indexReader.ts`** — parse `index.json`, return `ParsedIndex`
2. **`nodeReader.ts`** — parse node `.md` via `gray-matter`, return `ParsedNode` including `inferredFields: string[]`
3. **`treeProvider.ts`** — `HandoffTreeDataProvider` grouped by depth; checkmark prefix for read nodes
4. **`webviewPanel.ts`** — render node content via `marked`; show "AI-inferred" badge on fields in `inferredFields`; code ref click → navigate or resolve via git SHA
5. **`extension.ts`** — activation, `FileSystemWatcher` on `index.json`, command registration (`handoff.refresh`, `handoff.markAllRead`, `handoff.markAllUnread`)

### Phase 2 Gate

End-to-end test: clone a repo containing committed Handoff output → open in VS Code → browse all nodes → click at least one code reference → verify "AI-inferred" indicator appears on a node with `inferred_fields`. Must work offline.
